# Game-content boundary

The public repository and its release archives may contain only SSCVR's original source, documentation, tests, scripts, and compiled mod binaries.

Do not commit or attach any of the following:

- `SkillshotCity.exe` or any original game DLL
- the game's `data` directory or files copied from it
- textures, models, audio, maps, translations, or profile files
- captured or extracted game shaders
- Ghidra projects, decompiler output, memory dumps, or RenderDoc captures
- screenshots or video unless the contributor has separately confirmed they are suitable to publish
- Steam authentication data or personal logs
- Windows system DLLs

Executable hashes, offsets, API names, original SSCVR code, and short factual compatibility notes are allowed. A release installer must copy the user's own legitimate local installation into an isolated directory; it must never download or redistribute the game.
