# SSCVR

SSCVR is an early VR mod for Skillshot City. It renders the world from two viewpoints through OpenXR, adds bounded head tracking, and expands the normal render area for a tabletop-style view.

This repository contains SSCVR source code, build instructions, validation notes, and an installer for a separate verified Steam copy. It does not contain Skillshot City or any of its assets.

See [Building](docs/BUILDING.md) and [Validation](docs/VALIDATION.md) for development details.
